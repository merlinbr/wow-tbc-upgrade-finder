Design notes

Three spatial trees are shown together on desktop; narrow screens show one full-size tree through tabs. The reference supplies a layout direction, not an imported or read-only build. Icons and subdued backdrops are original neutral illustrations, not game artwork or a verified Forever catalog.

Only node selection, demo rank controls, mobile tabs, note disclosure and confirmed demo reset are interactive. The 18-point budget, sample names, positions, rank caps and prerequisites are synthetic; the class tree names are presentation labels. Existing unmet or unverified allocations remain visible and are not silently deleted.

Save, return and Gear/Stats controls are illustrative. Nothing is persisted, published or imported. Saving a private plan must not publish it; a failed save must preserve edits and leave the public page unchanged.
